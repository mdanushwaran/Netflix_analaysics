# 🎬 Netflix Analytics Dashboard | Power BI

## 📌 Project Overview

This project analyzes Netflix's content library using **Power BI** to uncover valuable insights into movies and TV shows available on the platform. The dashboard provides an interactive view of content distribution, ratings, genres, countries, release trends, and other key metrics to support data-driven decision-making.

---

## 🎯 Project Objective

The primary objective of this project is to analyze Netflix content and answer key business questions such as:

- What is the total number of Movies and TV Shows?
- Which genres are most popular?
- Which countries produce the most Netflix content?
- How has Netflix's content grown over the years?
- What are the most common content ratings?
- Which directors have released the most titles?

## 🧹 Data Cleaning Process

The following data preparation steps were performed:

- Imported dataset into Power BI
- Removed duplicate records
- Handled missing values
- Corrected data types
- Formatted date columns
- Standardized text values
- Split and transformed multiple-value columns
- Removed unnecessary columns

---

## 🔄 Data Transformation

Power Query was used to:

- Clean raw data
- Convert data types
- Replace null values
- Trim extra spaces
- Standardize country and genre names
- Create calculated columns

## 🔍 Business Insights

The dashboard helps answer the following questions:

- Which country has the highest number of Netflix titles?
- Which genres dominate the Netflix platform?
- What is the ratio of Movies to TV Shows?
- Which content ratings are most common?
- How has Netflix expanded its content over time?
- Which directors contribute the most titles?

---

## 💡 Key Findings

- Movies account for the majority of Netflix content.
- Drama and International Movies are among the most popular genres.
- The United States contributes the largest share of Netflix titles.
- Netflix has significantly increased its content library in recent years.
- TV Shows have shown steady growth alongside Movies.
